# مشروع HAKIM

هذا مشروع بداية لموقع تواصل اجتماعي مستقل باسم HAKIM، بواجهة عربية متوافقة مع الهاتف.

## ما الذي يتضمنه؟
- إنشاء حساب بالبريد الإلكتروني وكلمة مرور.
- تسجيل الدخول والخروج.
- قاعدة بيانات SQLite لحفظ الحسابات والمنشورات.
- كلمات المرور لا تُحفظ كنص واضح؛ تُخزّن كقيمة تجزئة باستخدام bcrypt.
- جلسات دخول محفوظة في SQLite.

## التشغيل على الكمبيوتر
1. ثبّت Node.js إصدار 20 أو أحدث.
2. فك ضغط الملف.
3. افتح الطرفية داخل مجلد المشروع.
4. نفّذ: `npm install`
5. أنشئ قيمة سرية طويلة لمتغير `SESSION_SECRET`.
6. شغّل: `npm start`
7. افتح `http://localhost:3000`.

## النشر على Render
- أنشئ Web Service جديداً واربطه بمستودع GitHub الذي يحتوي ملفات المشروع.
- Build Command: `npm install`
- Start Command: `npm start`
- أضف متغير البيئة `SESSION_SECRET` بقيمة عشوائية طويلة.
- أضف قرصاً دائماً (Persistent Disk) إلى `/var/data`.
- أضف `DB_PATH=/var/data/hakim.sqlite`.
- استخدم HTTPS، ولا تشارك متغيرات البيئة أو كلمات المرور.

## مهم
هذا قالب تعليمي أولي وليس منصة جاهزة للإطلاق العام. قبل فتح التسجيل للجمهور، أضف التحقق من البريد الإلكتروني، وسياسة خصوصية وشروط استخدام، وحماية CSRF، ومراجعة أمنية واختبارات نسخ احتياطي. لا تستخدمه لانتحال فيسبوك أو لجمع بيانات دخول مستخدميه. اجعل المستخدمين يعرفون بوضوح أنهم يسجلون في HAKIM.
